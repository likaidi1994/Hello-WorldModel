# 世界模型学习路线

这份路线会随着学习不断调整。它的作用是帮助自己和后来的读者知道：现在在学什么、为什么学、下一步往哪里走。

## 阶段 0：准备工作

- 熟悉 Git 和 GitHub 的基本工作流。
- 熟悉 Python、PyTorch、Jupyter Notebook 的基本使用。
- 建立项目目录、README、笔记模板和代码实验目录。

## 阶段 1：核心直觉

- 理解“模型学习环境动态”的含义。
- 区分 observation、state、action、reward、transition。
- 理解 latent dynamics model 的基本思想。
- 思考世界模型和人类想象、规划之间的关系。

## 阶段 2：经典论文

- World Models
- PlaNet
- Dreamer 系列
- MuZero

每篇论文建议记录：

- 论文想解决的问题。
- 方法的核心结构。
- 最重要的一张图或一个公式。
- 自己真正理解的部分。
- 仍然困惑的问题。

## 阶段 3：最小实验

- 从简单环境开始，例如 CartPole 或 GridWorld。
- 训练一个模型预测下一个状态。
- 尝试用预测结果辅助动作选择。
- 记录失败实验，而不仅是成功结果。

## 阶段 4：开源整理

- 把笔记整理成稳定章节。
- 给代码加上可复现实验说明。
- 增加引用、环境配置、贡献指南和任务列表。
- 邀请他人通过 Issue 参与讨论。
